# Scripts index

Python 3, standard library only (exception: `vlsit_analyze_excel.py` needs `openpyxl`) (rule RHD-090). Locate Python with `vlsit_find_python.ps1` (Windows) or `vlsit_find_python.sh` (Linux/macOS), then use its printed path (RHD-103). Register every script here (RHD-091); scripts obey `rule.md` (RHD-092).

| Script | Purpose | Status |
| `vlsit_find_python.ps1`, `vlsit_find_python.sh` | Locate working Python 3 on Windows or Linux/macOS and print its executable path. | Available; not re-tested in this review |
|---|---|---|
| `vlsit_rtl_hier.py` | Module inventory, instance tree to a depth, port tables (`--ports`), Markdown output (`--md`) for analysis stage 1 (RHD-030..033). Read only (RHD-002). `python scripts/vlsit_rtl_hier.py <RTL_DIR> [--top M] [--depth N] [--ports M] [--md]` | Tested on the CAN RTL (3 level-1 instances, 15 `can_ibo`, unreferenced `can_register_syn`, line numbers match the files) |
| `vlsit_drawio_frame_diagram.py` | Generates `vlsit_rtl_hierarchy.drawio` from a JSON spec with exactly two tabs: `BLOCK_DIAGRAM` (hierarchy and interfaces only) and `BLOCK_INFORMATION` (function table, interface table and symbol legend). `python scripts/vlsit_drawio_frame_diagram.py SPEC.json OUT_DIR`; schema in `reference/vlsit_diagram_spec.md` | See the bundled example input in `reference/examples/`; do not treat its legacy rendered output as the current two-tab layout. |
| `vlsit_drawio_nested_diagram.py` | Generates the same two-tab `vlsit_rtl_hierarchy.drawio` for hierarchy level N >= 2: nested frames (a module with children, or functional groups, inside the top frame), blocks on one global grid with optional heights, one connector per sink for a multi-sink interface, distribution trees (clock/reset, host bus) routed branch by branch with overlap inside one net, wider spacing for pad stubs, label placement that avoids frame borders, a PNG preview (needs Pillow, optional) and a crossing breakdown in the report. `python scripts/vlsit_drawio_nested_diagram.py SPEC.json OUT_DIR [--seed N --gap-h N --gap-v N]`; schema extension in `reference/vlsit_diagram_spec.md`. | Tested on the I2C core at level 2 (9 blocks, 2 sub-frames, 3 trees): library validator PASS, geometry check 0 findings. Rip-up and reroute lowers crossings but the I2C core still has up to 5 crossings among internal connectors (limit 2); the router is greedy, so the grid layout must be chosen by the user or by trying variants and seeds. |
| `vlsit_layout_search.py` | Runs the generator over parameter sets and ranks by crossings, bends, area (RHD-097). `python scripts/vlsit_layout_search.py SPEC.json PARAMS.txt WORK_DIR [--top N]` | Tested with 4 parameter sets |
| `vlsit_drawio_geometry_check.py` | Geometry review of a `.drawio`: connector through shapes, label overlaps, collinear overlaps, physical crossings, bends (RHD-079), text fill (RHD-052), frame ratio (RHD-087), page bounds. `--allow-shared-start` accepts one distribution tree (RHD-102). | Tested: 0 findings on the generated diagram, findings on a damaged copy |
| `vlsit_library_symbols.py` | Library catalog, template clone, and `validate --diagram FILE` for provenance, protected styles, groups, 18 pt black and white (RHD-061). Accepts `jumpStyle`/`jumpSize` (RHD-057) and skips native table cells tagged `vlsit_native_table="1"` (RHD-023). | Tested: PASS on the generated diagram (83 library cells, 2 pages) |
| `vlsit_analyze_excel.py` | Read-only analyzer for .xlsx/.xlsm/.xltx/.xltm/.xls/.xlsb/.csv: sheet summary, `--range`, `--search`, `--cells` dump, JSON output (RHD-105). Needs `openpyxl`. Maintained in this skill folder; keep the Codex and Claude copies synchronized. | Tested: openpyxl 3.x installed; workbook summary of a representative workbook (13 sheets) OK |
