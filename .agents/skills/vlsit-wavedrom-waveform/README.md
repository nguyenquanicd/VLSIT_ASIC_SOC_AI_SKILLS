# vlsit-wavedrom-waveform (Claude copy)

Draws timing waveforms with the bundled offline WaveDrom 3.7.0 (MIT). Input: a short request, a VCD file (whole file, time window or chosen signals) or a waveform image. Output: strict WaveJSON and a self-contained HTML viewer (opens offline, saves SVG/PNG). The skill asks about anything unclear, with options and explanations. Python 3 standard library only; no Node.js needed.

Vẽ waveform bằng WaveDrom 3.7.0 đi kèm (MIT), chạy ngoại tuyến. Đầu vào: yêu cầu ngắn, file VCD (toàn bộ, khoảng thời gian hoặc tín hiệu chọn) hoặc ảnh waveform. Đầu ra: WaveJSON và file HTML tự chứa (mở không cần Internet, lưu SVG/PNG). Skill hỏi lại các điểm chưa rõ kèm options và giải thích. Chỉ dùng thư viện chuẩn Python; không cần Node.js.
