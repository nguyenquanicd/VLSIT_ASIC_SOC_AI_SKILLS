# vlsit-create-skill (Claude copy)

Creates a new skill in the house format: `SKILL.md` (workflow), `rule.md` (numbered rules), `reference/`, `scripts/`. Interviews the user, offers design options with advantages and disadvantages, then validates and mirrors the skill with `scripts/vlsit_skillkit.py` (Python standard library only).

Tạo skill mới theo chuẩn: `SKILL.md` (quy trình), `rule.md` (rule có ID), `reference/`, `scripts/`. Skill phỏng vấn người dùng, đưa phương án thiết kế kèm ưu nhược điểm, rồi kiểm tra và đồng bộ bằng `scripts/vlsit_skillkit.py` (chỉ dùng thư viện chuẩn Python).

Invoke / Gọi: /vlsit-create-skill
