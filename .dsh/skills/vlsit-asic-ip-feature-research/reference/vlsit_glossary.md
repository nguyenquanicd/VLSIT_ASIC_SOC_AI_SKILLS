# Glossary

Expand these terms at first use in each report section or figure where a reader may encounter them independently. Preserve exact source identifiers, product names, signal names, standard names and patent identifiers.

| Abbreviation | Full term | Meaning in this skill |
|---|---|---|
| API | Application Programming Interface | Software-visible interface used by drivers or applications. |
| ASIC | Application-Specific Integrated Circuit | Integrated circuit tailored to a particular application. |
| CSV | Comma-Separated Values | Tabular text format used by the source manifest. |
| DOI | Digital Object Identifier | Persistent identifier used to deduplicate and locate scholarly works. |
| CDC | Clock-Domain Crossing | Signal or transaction crossing between unrelated or differently timed clock domains. |
| CPU | Central Processing Unit | General-purpose processor; expand only when used in prose. |
| CSR | Control and Status Register | Software-visible configuration or status register. |
| DMA | Direct Memory Access | Data transfer performed without the processor moving every data word. |
| FSM | Finite-State Machine | A set of states and transitions describing sequential behavior. |
| HTTP | Hypertext Transfer Protocol | Web transfer protocol; use only for directly accessible sources. |
| HTTPS | Hypertext Transfer Protocol Secure | Encrypted form of HTTP; encryption does not itself establish reuse rights. |
| I/O | Input/Output | Electrical or logical interface input/output; distinguish a logical port from a physical pad. |
| IP | Intellectual Property | Reusable hardware block or design in this research context; Internet Protocol is a different meaning. |
| LLC | Last-Level Cache | The final cache level before a memory or system interface, when applicable. |
| MMIO | Memory-Mapped Input/Output | Device registers or windows accessed through addressable memory transactions. |
| NPU | Neural Processing Unit or Network Processing Unit | Ambiguous; resolve from source context and spell out the selected meaning. |
| PHY | Physical-Layer Interface | Electrical/physical implementation layer for a communication link. |
| PPA | Power, Performance and Area | Common implementation trade-off dimensions; cite measurements or label estimates. |
| SoC | System-on-Chip | Integrated system containing processor, memory and/or peripheral blocks. |
| SHA-256 | Secure Hash Algorithm 256-bit | Digest algorithm used to detect changes in retained source files. |
| UART | Universal Asynchronous Receiver/Transmitter | Asynchronous serial communication controller; actual framing must be stated. |
| URL | Uniform Resource Locator | Address of a source or document; preserve the canonical link. |
| UTC | Coordinated Universal Time | Time basis recorded for source acquisition. |
| VPU | Vector Processing Unit or Video Processing Unit | Ambiguous; resolve from source context and spell out the selected meaning. |

This glossary is scoped to the skill. Add terms required by the selected IP or standards. Do not invent an expansion for a brand, product label, identifier or a source-specific acronym. If the source does not define an abbreviation, quote it as an undefined source term and ask or investigate before interpreting it.
